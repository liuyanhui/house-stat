# 周度成交趋势文字分析 — 需求文档 v0.3

> 版本史：v0.1（2026-10-30，基于当日对话分析定稿口径）→ v0.2（2026-10-30）：吸收第一轮三角色评审（产品/数据分析师/QA）——进行中周重定义与同期对齐、节假日周中断计数与工作日净额判定、锚点机制重构（段界定符 + wk_facts.json）、数字预算计数口径、持平周语义、边界补全 → **v0.3（2026-10-30）**：吸收第二轮架构评审——降级语义闭环（narrative=false）、双实现交叉验证、json 字段分层（只存数值/布尔/枚举）、禁用词扫描进 verify 门、渲染纯函数与抽模块判据。

## 0. 已裁决决策（2026-10-30 对话定，不再重议）

| # | 决策 | 结论 |
|---|---|---|
| D1 | 读者口径 | **普通读者**（无分析背景），非分析师；措辞按此纪律 |
| D2 | 叙述框架 | 回答三问：**方向**（连涨/连跌/互现）、**水位**（vs 半年周均）、**最新**（进行中周日均）；不用 4v4 百分比 |
| D3 | 窗口 | **4 完整周**（动能/近月）· **13 周**（峰谷表述）· **26 周**（水位基准） |
| D4 | 实现路线 | 全程确定性代码：`metrics` 算事实 dict → `report` 模板渲染；**AI 不进主报告**（"代码拥有数字，AI 只拥有叙述"，AI 不进 cron） |
| D5 | 范围 | 仅二手住宅周度；新房周度叙述不做（序列 2026-08 下旬起，太短） |

## 1. 目标与边界

- **目标**：报告第三节（周度成交趋势）新增一段 3~4 句的趋势文字，让普通读者不看图也知道"最近市场怎么样、往哪个方向走"。
- **不做**：预测类表述；新房周度叙述；AI 生成正文；新图表；html_render 改动（纯 md 段落直通，`<!-- -->` 注释直通）；周度以外的粒度变化。

## 2. 功能需求

### 2.1 叙述三问（必答，缺数据时按 §2.4 降级）

1. **方向**：末尾连续上涨/下跌周数（"连续 2 周回升"，周数一律阿拉伯数字）；涨跌互现时如实输出"近期有涨有跌，没有明确方向"，**不硬造趋势**。计数规则见 §2.3（节假日周/持平周/缺口均中断；**不设最小幅度门槛**——实测周环比中位约 ±20%、仅 7.6% 落 ±3% 内，门槛形同虚设）。
2. **水位**：近 4 完整周均 vs 近 26 周均。**差在 ±5% 以内输出"与最近半年大体相当"，不作高低判断**（26 周窗横跨旺淡两季，防日历效应误读）。
3. **最新**：**进行中周** = 末周且 `week_start + 6 天 > 数据末日`（注意：days<7 的历史周是节假日/缺口所致，**不是**进行中周）。对比用**同期对齐**：与上一周相同星期位置的相同天数窗口比日均（实测工作日日均约 620 套、周六/周日约 215/151 套，构成不对等，直接日均对比会系统性高估）。本周已完整时，本问并入方向句，不重复表述。

### 2.2 措辞纪律（普通读者）

- **结论前置**：第一句 = 方向 + 水位判断，加粗。
- **数字预算**：全段统计数字 **≤6**。**计数口径（正则可执行）：千分位模式 `\d{1,3}(,\d{3})+` 与"日均 N"（N 为阿拉伯数字）计入**；中文数词（"两周""三个月"）、窗口周数（4/26 周）、旬、日期码不计。
- 套数用精确值（2,098 套），**比率口语化**（"大约回到 9 月初水平"，不写 -15.9%）。时间锚点生成规则：在近 13 周内取与近 4 周均最接近的周、以旬表述；无匹配（创新高/新低）回退"处于近三个月高位/低位"。
- **时间锚点口语化**："X 月上/中/下旬"（1–10 / 11–20 / 21–月末）；节假日周直接用节日名（"国庆假期那周"）。日期码至多括注一处。
- **节假日解释口语化**：叙述涉及节假日周 → 必须带解释句（"假期签约少是每年惯例，不是市场转冷"）。
- **估算标注**：峰谷值含估算 → 值后最小括注"（含估算）"；连涨/跌链含估算周 → 在**段末说明句**带出（"文中'连续 2 周'含 1 个估算周"），不进叙述句。
- **禁用词**：封闭词表（预计 / 有望 / 或将 / 拐点 / 动能 / 窗口均值 / 口径 / 回暖 / 走强 / 走弱），常量单一来源放 `analysis/verify.py`（扫描执行处，tests 从此导入）；**扫描仅限叙述段**，verify 门与测试双层执行。
- **段落界定**：叙述段以 `<!-- wk-narrative -->`（起止各一）包裹，供 verify 定界与测试断言。

### 2.3 统计口径

- 仅**完整周**（days≥7）参与方向/水位/峰谷统计；进行中周只用同期对齐日均（既有 O1 纪律）。
- **节假日周定义**：`chinese_calendar` 判定**周内工作日净额 ≤3 天**（含调休；纯"法定假日 ≥3 天"识别不了调休补班与 1 天桥假）。
- **节假日周**：中断连涨连跌计数（不计为跌/涨周——否则节后每年准点出现机械性"连涨"）；作为峰谷出现时**必须用节日名表述 + 惯例解释句**，禁止单独说"近三个月低点"。
- **持平周**（相邻周差 = 0）：中断计数，归入互现。
- **估算周**（est_days>0）：参与计数**不中断**（估算经月度对账校准，方向大体可信），标注按 §2.2；沿用 `weekly_aggregate` 的 est_days 传播，不重复实现。
- **周序列缺口**（相邻 week_start 差 >7 天）：中断计数（防御性，当前序列连续）。
- 峰谷表述限 13 周内（"近三个月高点/低点"）。

### 2.4 降级规则

| 条件 | 行为 |
|---|---|
| 完整周 <26 | 水位句退化为"有数据以来"基准；不足 13 周时省略水位句 |
| 完整周 <8 | **整段不输出**（图+表仍在；wk_note 不恢复——其信息已由近 10 周表承载）；`wk_facts.json` 仍落盘且 `narrative=false` |
| 进行中周 days<3 | 不写"最新"句（样本太少） |
| 尾部多周缺天（上一周也不完整且非节假日） | "最新"句跳过上周对比，仅报本周情况；持续滞后由既有 `check_daily_freshness` 告警，本段不重复职责 |
| 无节假日周涉及 | 不出现节假日解释句 |
| est×节假日同周叠加 | 两句式并存：节日名表述在前，"（含估算）"括注随后 |
| 等值边界（恰好 8/13/26 完整周） | ≥ 即启用对应句式 |

### 2.5 集成

- **位置**：第三节，周度趋势图之后、近 10 周表之前。
- **整合 wk_note**：叙述段吸收现有"最新周"注释句（report.py wk_note 分支）的信息，**取代之**，同信息不双处呈现。
- **代码触点**：`analysis/metrics.py` 新增事实函数（纯数据 dict，不含文案）；`analysis/report.py` 渲染模板，**渲染为纯函数**（facts dict→str，不反查 CSV/weekly）；降级矩阵 + 模板合计超约 150 行时抽独立模块（如 `analysis/weekly_narrative.py`）；`analysis/verify.py` 新增锚点 + 禁用词表常量；`report/wk_facts.json` 与叙述段**同次 `generate()` 产出**（仿 kpi.json，供 verify 直比）；`tests/` 合成用例。charts/CHART_STEMS 不变。
- **既有测试同步**：whitelist.txt 中 wk_note 相关两行随移除登记更新；run_tests.py 的"进行中"断言来自新鲜度头，不受影响（已核实）。
- **ai_digest 增强（P2 可选）**：周度事实 dict 并入 ai_digest 导出；不阻塞本需求。

## 3. 验收标准（可测）

1. **verify 门新增**：
   - **json 字段分层**：只存数值/布尔/枚举——`narrative`（bool）、末完整周套数、方向枚举（up/down/mixed + 周数）、4/26 周均、水位枚举（above/below/parity，±5% 死区）、峰谷周值 + 估算布尔、进行中周套数/同期对齐日均/对比基期（上周同窗日均）/days；旬、节日名等**文案不进 json**，verify 只直比数值与枚举。
   - **事实锚点**：`report/wk_facts.json` 各字段从 `data/resale_daily.csv` **独立重算**（csv 直读、自建周分桶、nunique 天数、chinese_calendar 节假日净额判定，不经 load/metrics；`ESTIMATED_DAYS` 从 `quality.py` import，禁复制登记）直比 json；不符非零退出。
   - **降级一致性**：verify 独立数完整周数，<8 时要求 json `narrative=false` **且** md 无 `<!-- wk-narrative -->` 界定符对；二者不一致（有 json 无段落 / 有段落无 json / 应降级未降级）非零退出——区分设计性降级与渲染崩溃。
   - **md 锚点**：千分位数字仅在界定符段内匹配（近 10 周表会天然命中相同千分位，不界定则锚点失效）。
   - **措辞门**：段内禁用词扫描 + 数字预算计数断言进 verify 门（不只靠测试）。
2. **测试用例**（合成周数据进 tests/run_tests.py 体系；节假日用真实节假日日期如 2025-09-29 周（含 10-01~03），不 mock chinese_calendar）：连涨/连跌/互现三方向；持平周；缺口 >7 天；节假日周触发（中断计数/峰谷节日名表述/解释句）与不触发；est×节假日叠加；估算周标注传播；同期对齐对比；降级边界（<26 / <8 / 恰好 8/13/26、days<3、尾部多周缺天）；数字预算计数口径断言；禁用词扫描（限段内）；**交叉验证——同一合成 CSV 分别喂 metrics 事实函数与 verify 独立重算，逐字段相等（防双实现漂移）**；`wk_facts.json` 与叙述段一致性。
3. **人工抽查**：真实 80 周数据下输出通读一遍，符合 §2.2 措辞纪律；与图/表数字一致。

## 4. 明确不做

- 新房周度叙述（D5）；4v4/环比百分数进正文；AI 生成主报告文字；新图表或交互改动；最小幅度门槛（§2.1.1 实测否决）；周度叙述进摘要节——摘要仍只做月度，避免双处维护。
